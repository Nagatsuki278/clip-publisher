LOCAL VIDEO PUBLISHING TOOL

Publish short-form videos with less repetitive work.

Clip Publisher is a locally run Windows application for preparing short-form video titles, descriptions and captions, managing a video queue and assisting with publishing.

Current features

Drag-and-drop MP4 files, optional local file paths, AI-assisted captions through a configured FreeLLMAPI endpoint, YouTube upload through Google authorization, and manual browser-assisted posting to TikTok and Instagram.

TikTok integration

A TikTok API integration is planned for testing. Direct TikTok API upload is not available in the current version and depends on authorization and platform approval.
