Privacy Policy

Effective November 18, 2026

Local processing and storage

The current Clip Publisher application runs locally. It processes selected files and paths, captions, publishing settings and local upload history. Dragged-in videos are copied to a temporary folder. Google OAuth credentials and tokens are stored in local files; application configuration including AI credentials is stored locally.

External services

When you request AI captions, your written clip description is sent with authentication and model settings to the configured FreeLLMAPI endpoint. That endpoint may forward the request to another AI provider. When you request a YouTube upload, your selected video, metadata and publishing settings are sent to YouTube using Google authorization. For manual TikTok and Instagram posting, the application copies captions to the system clipboard and opens the respective website; you select and upload content there.

Planned TikTok integration

If enabled in a future version, TikTok authorization and upload may involve account identifiers, access or refresh tokens, selected videos, publication metadata and upload status. Such data would be used to authorize and complete the requested upload. This integration is not active in the current version; this policy must be updated to reflect the implemented data flows before it is enabled.

Retention and control

Local history remains until removed by the user. Temporary video copies can be cleared using the application or removed from the local temporary folder. You can delete local configuration, token and history files when the application is closed and revoke permissions through the relevant platform account settings. Third-party services retain data according to their own policies.

Website and contact

This static website has no custom analytics or forms. GitHub Pages may process visitor data under its own privacy policy. For privacy questions or requests, use GitHub project issues (do not post private information or credentials).
